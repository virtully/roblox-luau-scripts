# Roblox Luau scripts (free, type-checked)

120 Roblox systems and 340 scripts you can copy into Roblox Studio: doors, DataStores, RemoteEvents, shops, leaderboards, teleporters, NPC dialogue, cutscenes, game genres and more.

Every script:
- passes Luau's strict type checker (`luau-lsp`) against Roblox's API definitions,
- says at the top whether it is a Script, LocalScript or ModuleScript,
- links to a full guide on [rocode.app](https://www.rocode.app/guides) explaining where it goes, how it works and the errors you are likely to hit.

A type check catches misspelt APIs and wrong types, not game logic, so playtest in Studio before you publish.
